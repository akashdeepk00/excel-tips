Excel & Google Sheets Formula Reference

Text Manipulation

Clean Phone Numbers (12 to 10 digits)

=CLEAN(TRIM(IF(LEFT(P2,2)="91",IF(LEN(P2)=12,RIGHT(P2,10),P2),P2)))
Converts Indian phone numbers starting with '91' to 10-digit format while preserving other numbers.

Split Text at Character

=LEFT(text,FIND(character,text)-1)
=RIGHT(B5,LEN(B5)-FIND("_",B5))
Useful for splitting email addresses, file names, or any text containing a specific delimiter.

Count Specific Characters

=LEN(A2)-LEN(SUBSTITUTE(A2, "s", ""))
Count occurrences of any character in a cell. Common use: counting special characters or validating data format.

Date Functions

Calculate Age from DOB

=INT(YEARFRAC(TODAY(),F2,1))
Calculates current age based on date of birth, accounting for leap years.

Get Month Name from Serial Number

=TEXT(MONTH(E2)*29,"mmm")
Legacy formula that works (reason unknown for *29)
=TEXT(E2,"mmm")
Alternative: Direct conversion of date to month name

Lookup Functions

INDEX and MATCH

=INDEX($B$16:$B$27,MATCH(B7,$C$16:$C$27,0))
More flexible alternative to VLOOKUP. Useful for bi-directional lookups and when columns might change.

Two-way Lookup (Row and Column)

=VLOOKUP(row reference,<full array>,MATCH(col reference,<col array>,match_type))
Perfect for price tables, matrices, or any two-dimensional lookup scenarios.

Utility Functions

Dynamic Sheet Reference

=INDIRECT("'" & A1 & " days'!B5")
References cells across different sheets using dynamic sheet names.

Generate Sheet Names List

=REPLACE(GET.WORKBOOK(1),1,FIND("]",GET.WORKBOOK(1),""))
Creates a named range 'listsheets' containing all worksheet names.

Count Non-matching Cells

=COUNTIF(C:C, "<>absent")
Counts cells that don't match a specific value. Useful for attendance tracking or error checking.

Hyperlink Using Row and Column

=HYPERLINK("#'Rating_Structure'!" & ADDRESS(A2, B2), "Link Text")
Creates dynamic hyperlinks based on row and column references.

Sum Products of Columns

=SUMPRODUCT(column1, column2)
Multiplies corresponding values in two columns and sums the results.

VBA Functions

Extract URL from Hyperlink VBA

Function URL(Hyperlink As Range) URL = Hyperlink.Hyperlinks(1).Address End Function
Extracts the URL from a hyperlinked cell. Use with =URL(cell) after adding to VBA module.

Web Integration

Print Logos from Web

=IMAGE(CONCAT("https://logo.clearbit.com/", cell address, ".com"))
Automatically fetches company logos. Note: Requires Microsoft 365.
